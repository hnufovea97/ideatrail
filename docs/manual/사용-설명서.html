Ideatrail 사용 설명서

처음 쓰는 분을 위한 안내예요. 어려운 말은 맨 아래 낱말 풀이에 모아 두었어요. 곧 생겨요 표시는 아직 준비 중인 기능이에요.
이 설명서에서 Ideatrail은 서비스와 그 서버를, 사용자는 이 설명서를 읽는 분을 뜻해요.

1. Ideatrail이 뭐예요?

AI와 이야기하다 “이거 괜찮은데?” 싶으면, 한마디면 돼요.

AI와 이야기하다 보면 좋은 생각이 나와요. 그런데 대화가 길어지면 묻혀서, 며칠 뒤엔 무엇을 왜 골랐는지 다시 찾기 어렵죠. Ideatrail을 쓰면 “기록해 줘” 한마디로 AI가 그 순간을 정리해서, 날짜 증명과 함께 남겨요. “남겨 줘”, “적어 둬”처럼 사용자가 편한 말로 해도 돼요.

이렇게 써요

좋아, 이 방향으로 가자. 왜 이걸 골랐는지까지 기록해 줘

기록했어요 · 가계부 앱 · 단계: 기획 확정 (AI 추정)

나중엔 이렇게 한눈에 봐요 한눈에 보는 화면은 곧 생겨요

  1. 아이디어11월 3일처음 떠올린 생각
  2. 기획 확정11월 18일고른 것 카드 연동 없이 직접 입력 · 이유 금융 정보를 넘기기 싫어서 · 안 하기로 한 것 가족 공유

써 보면 좋은 점 세 가지

1

말 한마디로 정리돼요

“기록해 줘”라고 하면 AI가 대화에서 무엇을 골랐고, 왜 골랐고, 무엇을 안 하기로 했는지를 짧은 메모로 정리해 기록해요.

말하지 않아도 문서에 의미 있는 변화(기획 확정, 기능 완성, 피드백 반영 등)가 생기면 알아서 기록해요. 오타 고치기 같은 작은 변화는 남기지 않아요.

2

나중에 찾기 쉬워요

아이디어마다 어느 단계까지 왔는지(아이디어 → 기획 확정 → MVP 완료 → 기능 완성), 그때그때 고른 것과 그 이유가 순서대로 쌓여요.

지금은 Claude Code에 “아이디어 상태 알려줘”라고 물으면 알려 줘요. 휴대폰·다른 기기에서 한눈에 보는 화면은 곧 생겨요

원하면 그 기록의 파일로 가는 경로도 알려 줘요. 그 파일을 여는 순간부터는 사용자의 기기·GitHub 계정의 보안에 달려 있어요. 기록마다 날짜 증명이 붙어서 “이 생각을 이날 이만큼 해 두었다”를 누구에게나 보여 줄 수 있어요.

3

안심하고 맡겨요

기록 내용은 잠긴 채 사용자의 컴퓨터와 사용자의 GitHub에만 있고, 사용자의 열쇠로 사용자의 기기에서만 열려요.

Ideatrail 서버에 남는 것은 기록 일시와 파일 지문(기록마다 32바이트)뿐이에요. 지문은 내용에서 한 방향으로만 뽑은 값이라 서버가 해킹돼도 내용을 거꾸로 알아낼 수 없어요. 자세한 건 2장에 있어요.

가입하면서 아래 네 가지를 만들어요. 이 설명서는 이 네 가지 이름으로 이야기해요.

열쇠사용자의 컴퓨터 안

기록을 여는 열쇠. 컴퓨터 밖으로 나가지 않아요.

예비 열쇠사용자의 휴대폰 안

휴대폰으로도 보고, 컴퓨터를 잃어도 열 수 있어요.

증명 보관함사용자의 GitHub

잠긴 기록 사본과 날짜 증명. Ideatrail이 없어져도 남아요.

비상 열쇠종이·비밀번호 관리자

기기를 모두 잃었을 때 쓰는 마지막 열쇠예요.

Ideatrail 서버에 잠긴 채로만 있는 것

화면을 그리려면 필요해서, 사용자의 기기가 잠가서 보내는 작은 정보예요. 셋 다 사용자의 열쇠로만 풀려요. Ideatrail은 못 풀어요.

  1. 목록 이름표 — 목록에 보일 폴더 이름·파일 이름·단계
  2. 열쇠 상자 — 사용자의 컴퓨터·휴대폰·비상 열쇠가 같은 기록을 열 수 있게 해 주는 상자
  3. GitHub 출입증 — 대시보드가 사용자의 증명 보관함을 읽을 때 써요

그래서 이런 일이 생겨도 괜찮아요

만약어떻게 되나요
Ideatrail 서버가 털리면가져갈 내용이 없어요. 파일 지문으로는 내용을 되살리거나 짐작할 수 없고, 잠긴 정보는 열쇠가 없어 풀 수 없어요
Ideatrail 직원이 보려고 해도마찬가지예요. Ideatrail에는 열쇠가 없어요
GitHub 계정이 털리거나 GitHub가 들여다봐도잠긴 사본만 있어요. 사용자의 열쇠 없이는 못 열어요
Ideatrail이 문을 닫아도기록 사본은 사용자의 GitHub에, 작업 파일은 사용자의 컴퓨터에 그대로 있어요. 날짜 증명은 공개 블록체인에 새겨져서, Ideatrail 없이도 누구나 확인할 수 있어요
컴퓨터를 잃어도휴대폰(예비 열쇠)이나 비상 열쇠로 열고, GitHub의 사본으로 되찾아요 되찾는 화면은 곧 생겨요
AI가 마음대로 하려 해도기록 도우미 폴더는 AI도 열지 못하게 막혀 있어요. 공개·삭제·공유는 AI가 쓰는 도구에 아예 없어요

기록을 볼 때는

사용자의 기기 브라우저가 사용자의 GitHub에서 잠긴 사본을 가져와 그 자리에서 사용자의 열쇠로 풀어요. 푼 내용은 Ideatrail 서버로 보내지 않아요. 대시보드는 곧 생겨요

잠그는 방식은요

Ideatrail이 새로 만든 방식이 아니에요. 공개되고 검증된 표준 암호 방식을 써요(이름은 낱말 풀이에 있어요). 날짜는 기록 몇 시간 뒤 공개 블록체인에 새겨지고, 그 뒤에는 누구도 바꿀 수 없어요.

가입은 약 5분 걸려요.

4. 설치하기 곧 생겨요

플러그인으로 묶어 내놓는 일이 곧 끝나요. 아래는 그때의 설치 방법이에요.

  1. Claude Code를 열어요.
  2. 이 한 줄을 붙여 넣고 Enter를 눌러요.
    /plugin install ideatrail
  3. 끝이에요. 처음 무언가를 기록하려고 할 때 가입 창이 열려요.
Claude Code가 처음부터 실행되지 않으면, Ideatrail 문제가 아니라 Claude Code 로그인 문제일 때가 많아요. Claude Code 안내대로 다시 로그인해 주세요.

5. 가입하기 — 한 단계씩

Claude Code에 이런 한 줄이 보이면 가입이 시작된 거예요.

가입하려고 브라우저 창을 열었어요. 약 5분이면 끝나요. 화면이 하라는 대로 마친 뒤 여기 Claude Code로 돌아와 주세요.

브라우저에 첫 화면이 열려요. “이렇게 써요” 예시, 써 보면 좋은 점 세 가지, 안심하고 쓰는 이유(앞으로 만들 네 가지와 Ideatrail 서버에 무엇이 남는지)가 차례로 나와요. 화면 위의 "연결할 컴퓨터: (컴퓨터 이름)"이 사용자의 컴퓨터가 아니거나, Claude Code가 연 창이 아니라면 그냥 닫으세요.

[시작하기]를 누르면 1단계부터 시작해요. 단계가 끝날 때마다 다음 화면 맨 위에 "✓ 방금 한 일"이 한 줄로 나와요.

이 컴퓨터에 열쇠 만들기

하는 일
기록을 여는 열쇠를 이 컴퓨터 안에 만들어요. 열쇠는 Ideatrail 서버로 가지 않아요.
누를 것
[열쇠 만들기]
뜨는 창
브라우저가 "저장할까요?" 하고 작은 창을 띄워요. 창에 "패스키"라는 말이 보일 수 있어요.
  • Safari: [계속] → Touch ID에 손가락을 대거나 컴퓨터 암호를 넣어요.
  • Chrome: 저장할 곳을 물을 수 있어요. 안내대로 고른 뒤 Touch ID나 암호를 넣어요. 잘 모르겠으면 Safari가 가장 쉬워요.
  • Touch ID가 없어도 돼요. 컴퓨터 로그인 암호로 만들어져요.
가끔
"한 번만 더 확인할게요"가 나오면 [확인]을 눌러요. 열쇠를 마무리하려고 한 번 더 묻는 거예요.

✓ 이 컴퓨터에 열쇠를 만들었어요. 사용자의 기록은 이 열쇠로만 열려요

휴대폰에 예비 열쇠 만들기

하는 일
휴대폰에도 열쇠를 하나 더 만들어요. 컴퓨터를 잃어도 휴대폰으로 열 수 있어요.
할 것
  1. 휴대폰 카메라 앱을 켜고 화면의 QR 코드를 비춰요.
  2. 카메라 화면에 뜬 링크를 눌러요. 휴대폰 브라우저가 열려요.
  3. [이 기기 잠금으로 등록]을 누르고 휴대폰 잠금(얼굴·지문·PIN)을 한 번 풀어요.
  4. 휴대폰에 "이 기기에서도 열려요"가 나오면 끝. 컴퓨터 화면은 저절로 넘어가요.
알아 둘 것
QR은 2분만 써요. 지나면 새 QR이 저절로 나와요. 찍을 수 없으면 [QR을 찍을 수 없어요] → [링크 복사]로 사용자의 휴대폰에만 보내세요. 이 링크는 한 번만 쓰는 비밀이라 다른 사람에게 보내면 안 돼요.
휴대폰이 없으면
[휴대폰이 지금 없어요]로 건너뛰어요. 이때는 4단계 비상 열쇠를 꼭 만들어야 해요.

✓ 휴대폰에 예비 열쇠를 만들었어요. 이제 휴대폰으로도 볼 수 있어요

증명 보관함 만들기 (사용자의 GitHub)

하는 일
사용자의 GitHub에 비공개 보관함을 하나 만들어요. 잠긴 기록 사본과 날짜 증명이 여기 쌓여요. Ideatrail 앱은 이 보관함 하나에만 쓸 수 있어요.
할 것
  1. [GitHub에 보관함 만들기]를 눌러요.
  2. "ideatrail" 작은 창에 8자리 코드(예: ABCD-1234)가 보여요. 이미 복사돼 있어요.
  3. 열린 GitHub 화면에 로그인해요(계정이 없으면 무료로 만들 수 있어요).
  4. 코드 칸에 붙여넣기(Cmd+V) → [Continue].
  5. "Ideatrail"을 설치·승인할지 물으면 [Install], [Authorize].
  6. 가입 화면으로 돌아오면 저절로 다음 단계에 가 있어요.
나중에 해도 돼요
[나중에]를 누르면 마지막 화면에서 [지금 만들기]로 다시 할 수 있어요.

✓ 사용자의 GitHub에 증명 보관함을 만들었어요. Ideatrail이 없어져도 증명이 남아요

비상 열쇠 중요

하는 일
컴퓨터와 휴대폰을 모두 잃었을 때 쓰는 마지막 열쇠예요. Ideatrail도 대신 열어 드릴 수 없어서 꼭 보관해야 해요.
보관할 곳
비밀번호 관리자(iCloud 키체인, 1Password 등)에 [비상 열쇠 복사]로 붙여 넣거나, PDF·종이로 인쇄해 서랍처럼 안전한 곳에 둬요.
꼭 기억
비상 열쇠는 딱 한 번만 보여요. 4글자씩 끊어 천천히 확인하세요. [다 보관했어요] → 앞 4자리 입력 → [확인하고 저장](Touch ID·암호 한 번).
건너뛰기
휴대폰을 등록했다면 [나중에]도 돼요. 휴대폰을 건너뛰었다면 지금 꼭 만들어야 해요.

✓ 비상 열쇠를 보관했어요. 기기를 모두 잃어도 이걸로 다시 열 수 있어요

지금 Claude Code에서 연 프로젝트가 맨 위에 켜져 있고, 옆의 아이디어 폴더 몇 개가 꺼진 채 보여요. 원하는 것만 켜고 [기록하기](Touch ID·암호 한 번).
알아 둘 것
아무것도 안 고르면 [새 기록부터 시작하기]가 돼요. 날짜 증명은 오늘 날짜로 찍히고, 문서의 원래 날짜는 참고로 붙어요. 한 번에 200개 문서까지 가져오고, 나머지는 다음에 바뀔 때 기록해요.

마지막 화면 "준비됐어요"에서 만든 네 가지가 어디 있는지 다시 보여 줘요. 건너뛴 것은 "아직 안 만들었어요"로 나와요. 그다음 [터미널로 돌아가기]를 누르거나 창을 닫고 Claude Code로 돌아가면 돼요.

6. 평소에 쓰기

평소처럼 Claude Code와 이야기하세요. “이거 괜찮은데?” 싶은 순간엔 “기록해 줘” 한마디면 돼요. 말하지 않아도 기획 확정, 기능 완성, 피드백 반영처럼 의미 있는 변화가 생기면 기록 도우미가 남기고 터미널에 한 줄로 알려 줘요. 오타 고치기 같은 작은 변화는 기록하지 않아요.

10. 자주 묻는 질문

Ideatrail이 사용자의 아이디어를 볼 수 있나요?

아니요. 기록 내용은 Ideatrail 서버로 오지 않아요. Ideatrail에는 기록 일시와 파일 지문만 있고, 여는 열쇠도 없어요. 자세한 것은 2장을 보세요.

AI가 사용자의 기록을 마음대로 공개하거나 지울 수 있나요?

아니요. 공개·삭제·공유는 AI 도구에 아예 없어요. 대시보드에서 사용자가 기기 잠금을 풀어야만 할 수 있어요.

모든 변화가 기록되나요?

아니요. 기획 확정, 기능 완성, 피드백 반영처럼 의미 있는 변화만 남겨요. 오타 수정은 기록하지 않아요.

"AI 추정"은 뭐예요?

AI가 문서를 보고 "이제 기획 확정 단계 같아요"라고 짐작했다는 뜻이에요. 사용자가 직접 말하면 붙지 않아요.

GitHub를 안 쓰면 안 되나요?

가입 때 [나중에]로 건너뛸 수 있어요. 다만 증명 보관함이 있어야 Ideatrail이 없어져도 기록 사본과 증명이 사용자 손에 남아요.

휴대폰 없이도 쓸 수 있나요?

네. 대신 비상 열쇠는 꼭 만들어야 해요. 컴퓨터를 잃으면 비상 열쇠만 남거든요.

비상 열쇠를 잃어버렸어요.

컴퓨터나 휴대폰이 남아 있다면 계속 쓸 수 있어요. 새 비상 열쇠를 만드는 화면은 곧 생겨요. 기기도 비상 열쇠도 모두 잃으면 Ideatrail도 열어 드릴 수 없어요.

가입 링크가 "시간이 지났어요"라고 나와요.

Claude Code에 "설치 링크 다시 줘"라고 말해 주세요. 새 가입 창이 열려요.

Windows에서도 되나요?

곧 생겨요. 지금은 Mac에서 먼저 써 볼 수 있어요.
