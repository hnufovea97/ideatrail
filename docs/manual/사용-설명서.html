Ideatrail 사용 설명서

처음 쓰는 분을 위한 안내예요. 어려운 말은 맨 아래 낱말 풀이에 모아 두었어요. 곧 생겨요 표시는 아직 준비 중인 기능이에요.

1. Ideatrail이 뭐예요?

  • AI(Claude Code)와 아이디어를 다듬는 동안, 의미 있는 변화가 생길 때마다 저절로 기록해 줘요.
  • 기록마다 날짜 증명이 붙어요. "이 아이디어를 이날 이만큼 해 두었다"를 나중에 보여 줄 수 있어요.
  • 기록의 내용은 우리 서버에 두지 않아요. 서버에는 날짜를 증명할 파일 지문(내용에서 뽑은 짧은 값)만 있어요. 내용은 잠긴 채 내 GitHub와 내 컴퓨터에 있고, 볼 때는 내 열쇠로 내 기기에서 열어요.

가입하면서 아래 네 가지를 만들어요. 이 설명서는 이 네 가지 이름으로 이야기해요.

열쇠이 컴퓨터 안

내용을 여는 열쇠. 컴퓨터 밖으로 나가지 않아요.

예비 열쇠휴대폰 안

휴대폰으로도 보고, 컴퓨터를 잃어도 열 수 있어요.

증명 보관함내 GitHub

날짜 증명과 잠긴 원문. 우리 서비스가 없어져도 남아요.

비상 열쇠종이·비밀번호 관리자

기기를 모두 잃었을 때 쓰는 마지막 열쇠예요.

2. 무엇이 필요해요?

필요한 것왜 필요해요?
Mac Windows는 곧 생겨요기록이 남는 컴퓨터예요
Claude Code평소 AI와 작업하는 곳이에요. 기록 도우미가 여기 들어가요
Chrome 또는 Safari 최신 버전가입 화면을 열어요
Touch ID 또는 컴퓨터 로그인 암호컴퓨터 안에 열쇠를 만들 때 써요
휴대폰 (있으면 좋아요)예비 열쇠를 만들어요. 없으면 건너뛸 수 있어요
GitHub 계정 (무료)내 증명 보관함을 둘 곳이에요. 나중에 만들어도 돼요
비밀번호 관리자나 프린터비상 열쇠를 보관해요

가입은 약 5분 걸려요.

3. 설치하기 곧 생겨요

플러그인으로 묶어 내놓는 일이 곧 끝나요. 아래는 그때의 설치 방법이에요.

  1. Claude Code를 열어요.
  2. 이 한 줄을 붙여 넣고 Enter를 눌러요.
    /plugin install ideatrail
  3. 끝이에요. 처음 무언가를 기록하려고 할 때 가입 창이 열려요.
Claude Code가 처음부터 실행되지 않으면, Ideatrail 문제가 아니라 Claude Code 로그인 문제일 때가 많아요. Claude Code 안내대로 다시 로그인해 주세요.

4. 가입하기 — 한 단계씩

Claude Code에 이런 한 줄이 보이면 가입이 시작된 거예요.

가입하려고 브라우저 창을 열었어요. 약 5분이면 끝나요. 화면이 하라는 대로 마친 뒤 여기 Claude Code로 돌아와 주세요.

브라우저에 "시작하기 전에" 화면이 열리고, 앞으로 만들 네 가지가 그림으로 나와요. 화면 위의 "연결할 컴퓨터: (내 컴퓨터 이름)"이 내 컴퓨터가 아니거나, Claude Code가 연 창이 아니라면 그냥 닫으세요.

[시작하기]를 누르면 1단계부터 시작해요. 단계가 끝날 때마다 다음 화면 맨 위에 "✓ 방금 한 일"이 한 줄로 나와요.

이 컴퓨터에 열쇠 만들기

하는 일
내용을 여는 열쇠를 이 컴퓨터 안에 만들어요.
누를 것
[열쇠 만들기]
뜨는 창
브라우저가 "저장할까요?" 하고 작은 창을 띄워요. 창에 "패스키"라는 말이 보일 수 있어요.
  • Safari: [계속] → Touch ID에 손가락을 대거나 컴퓨터 암호를 넣어요.
  • Chrome: 저장할 곳을 물을 수 있어요. 안내대로 고른 뒤 Touch ID나 암호를 넣어요. 잘 모르겠으면 Safari가 가장 쉬워요.
  • Touch ID가 없어도 돼요. 컴퓨터 로그인 암호로 만들어져요.
가끔
"한 번만 더 확인할게요"가 나오면 [확인]을 눌러요. 열쇠를 마무리하려고 한 번 더 묻는 거예요.

✓ 이 컴퓨터에 열쇠를 만들었어요. 이 열쇠 없이는 우리도 못 열어요

2 / 5

휴대폰에 예비 열쇠 만들기

하는 일
휴대폰에도 열쇠를 하나 더 만들어요. 컴퓨터를 잃어도 휴대폰으로 열 수 있어요.
할 것
  1. 휴대폰 카메라 앱을 켜고 화면의 QR 코드를 비춰요.
  2. 카메라 화면에 뜬 링크를 눌러요. 휴대폰 브라우저가 열려요.
  3. [이 기기 잠금으로 등록]을 누르고 휴대폰 잠금(얼굴·지문·PIN)을 한 번 풀어요.
  4. 휴대폰에 "이 기기에서도 열려요"가 나오면 끝. 컴퓨터 화면은 저절로 넘어가요.
알아 둘 것
QR은 2분만 써요. 지나면 새 QR이 저절로 나와요. 찍을 수 없으면 [QR을 찍을 수 없어요] → [링크 복사]로 내 휴대폰에만 보내세요. 이 링크는 한 번만 쓰는 비밀이라 다른 사람에게 보내면 안 돼요.
휴대폰이 없으면
[휴대폰이 지금 없어요]로 건너뛰어요. 이때는 4단계 비상 열쇠를 꼭 만들어야 해요.

✓ 휴대폰에 예비 열쇠를 만들었어요. 이제 휴대폰으로도 볼 수 있어요

3 / 5

증명 보관함 만들기 (내 GitHub)

하는 일
내 GitHub에 비공개 보관함을 하나 만들어요. 날짜 증명과 잠긴 원문이 여기 쌓여요. 우리는 이 보관함 하나에만 들어갈 수 있어요.
할 것
  1. [GitHub에 보관함 만들기]를 눌러요.
  2. "ideatrail" 작은 창에 8자리 코드(예: ABCD-1234)가 보여요. 이미 복사돼 있어요.
  3. 열린 GitHub 화면에 로그인해요(계정이 없으면 무료로 만들 수 있어요).
  4. 코드 칸에 붙여넣기(Cmd+V) → [Continue].
  5. "Ideatrail"을 설치·승인할지 물으면 [Install], [Authorize].
  6. 가입 화면으로 돌아오면 저절로 다음 단계에 가 있어요.
나중에 해도 돼요
[나중에]를 누르면 마지막 화면에서 [지금 만들기]로 다시 할 수 있어요.

✓ 내 GitHub에 증명 보관함을 만들었어요. 우리 서비스가 없어져도 증명이 남아요

4 / 5

비상 열쇠 중요

하는 일
컴퓨터와 휴대폰을 모두 잃었을 때 쓰는 마지막 열쇠예요. 우리도 대신 열어 드릴 수 없어서 꼭 보관해야 해요.
보관할 곳
비밀번호 관리자(iCloud 키체인, 1Password 등)에 [비상 열쇠 복사]로 붙여 넣거나, PDF·종이로 인쇄해 서랍처럼 안전한 곳에 둬요.
꼭 기억
비상 열쇠는 딱 한 번만 보여요. 4글자씩 끊어 천천히 확인하세요. [다 보관했어요] → 앞 4자리 입력 → [확인하고 저장](Touch ID·암호 한 번).
건너뛰기
휴대폰을 등록했다면 [나중에]도 돼요. 휴대폰을 건너뛰었다면 지금 꼭 만들어야 해요.

✓ 비상 열쇠를 보관했어요. 기기를 모두 잃어도 이걸로 다시 열 수 있어요

5 / 5

기록할 것 고르기

하는 일
이미 있는 문서로 아이디어마다 어디까지 왔는지 바로 채워요.
할 것
지금 Claude Code에서 연 프로젝트가 맨 위에 켜져 있고, 옆의 아이디어 폴더 몇 개가 꺼진 채 보여요. 원하는 것만 켜고 [기록하기](Touch ID·암호 한 번).
알아 둘 것
아무것도 안 고르면 [새 기록부터 시작하기]가 돼요. 날짜 증명은 오늘 날짜로 찍히고, 문서의 원래 날짜는 참고로 붙어요. 한 번에 200개 문서까지 가져오고, 나머지는 다음에 바뀔 때 기록해요.

마지막 화면 "준비됐어요"에서 만든 네 가지가 어디 있는지 다시 보여 줘요. 건너뛴 것은 "아직 안 만들었어요"로 나와요. 그다음 [터미널로 돌아가기]를 누르거나 창을 닫고 Claude Code로 돌아가면 돼요.

5. 평소에 쓰기

따로 할 일은 없어요. 평소처럼 Claude Code와 작업하세요. 기획 확정, 기능 완성, 피드백 반영처럼 의미 있는 변화가 생기면 기록 도우미가 남기고 터미널에 한 줄로 알려 줘요. 오타 고치기 같은 작은 변화는 기록하지 않아요.

기록했어요 · 가계부 앱 · 단계: 기획 확정 (AI 추정)

이렇게 말해 보세요

말하기일어나는 일
"아이디어 상태 알려줘"이 프로젝트의 지금 단계와 기록이 있는지 알려 줘요
"지금 기록해 줘"방금 바뀐 내용을 기록해요
"기획 확정됐어. 기록해 줘"단계를 '기획 확정'으로 남겨요. 내가 말했으니 "AI 추정"이 안 붙어요
"옆 폴더의 예전 노트도 가져와 줘"그 폴더를 기록할지 묻는 요청을 보내요. 허락하는 화면은 곧 생겨요
  • 작업을 마칠 때 아직 기록하지 않은 변경이 있으면 Claude가 "ideatrail에 남길까요?"라고 한 번 물어요.
  • 인터넷이 끊겨도 괜찮아요. 연결되면 저절로 올라가요.
  • 공개로 바꾸기·지우기·공유는 AI가 할 수 없어요. 대시보드에서 본인만 할 수 있어요 대시보드는 곧 생겨요

6. 휴대폰으로 보기

  • 2단계에서 예비 열쇠를 만들었다면 휴대폰으로 볼 준비가 된 거예요.
  • 휴대폰 브라우저 메뉴(⋮)에서 "홈 화면에 추가"를 누르면 앱처럼 열 수 있어요.
  • 기록을 둘러보는 대시보드 화면은 곧 생겨요

7. 내 데이터는 어떻게 돼요?

  • 기록의 내용(메모·원본 파일)은 우리 서버로 보내지 않아요. 이 컴퓨터에서 잠근 뒤 내 GitHub(증명 보관함)로 바로 가요.
  • 우리 서버에 있는 것은 세 가지뿐이에요.
    1. 파일 지문 — 내용에서 뽑은 짧은 값이에요. 이것만으로는 내용을 되살리거나 짐작할 수 없어요.
    2. 날짜 증명 — 그 지문이 언제 있었는지 보여 줘요.
    3. 잠긴 이름표 — 목록에 보일 폴더 이름·파일 이름이에요. 이것도 잠겨 있어서 우리는 못 봐요.
  • 볼 때는 내 기기의 브라우저가 내 GitHub에서 잠긴 기록을 가져와 내 열쇠로 그 자리에서 열어요(대시보드는 곧 생겨요).
  • 잠그는 방식은 우리가 새로 만든 것이 아니라 공개되고 검증된 표준 암호 방식이에요.
  • 여는 열쇠는 내 컴퓨터와 휴대폰 안에만 있어요. 우리 서버로 오지 않아요.
  • 증명 보관함(내 GitHub)에 날짜 증명과 잠긴 원문이 쌓여요. 이 보관함에는 내 컴퓨터의 기록 도우미만 써요. 우리 서버는 GitHub에 쓰지 않고, 다른 저장소에도 들어가지 못해요.
  • 컴퓨터 홈 폴더의 ideatrail-증명 폴더에도 사본이 하나 더 남아요.
  • 기록 도우미가 쓰는 폴더는 AI도 열지 못하게 막혀 있어요.
  • 날짜 증명은 몇 시간 뒤 공개 블록체인에 새겨져요. 그 뒤에는 누구도 날짜를 바꿀 수 없어요.

8. 기기를 잃어버렸다면

잃은 것이렇게 하세요
컴퓨터만휴대폰(예비 열쇠)으로 계속 열 수 있어요. 새 컴퓨터는 휴대폰에서 [새 기기 추가]로 등록해요 곧 생겨요
휴대폰만컴퓨터(열쇠)로 계속 열 수 있어요. 새 휴대폰은 컴퓨터에서 [새 기기 추가]로 등록해요 곧 생겨요
둘 다비상 열쇠로 새 기기에서 다시 열어요 곧 생겨요 비상 열쇠가 없으면 우리도 열어 드릴 수 없어요
그래서 비상 열쇠가 중요예요. 아직 안 만들었다면 설정에서 만들 수 있게 될 거예요 곧 생겨요

9. 연결 끊기와 계정 지우기

  • 이 컴퓨터에서 그만 쓰기: Claude Code의 /plugin 메뉴에서 ideatrail을 끄거나 지우면 더는 기록하지 않아요.
  • GitHub 연결 끊기: GitHub 설정 → Applications에서 Ideatrail을 지우면 기록 도우미가 보관함에 더 쓸 수 없어요. 이미 쌓인 증명은 그대로 남아요. 보관함 자체는 GitHub에서 직접 지울 수 있어요.
  • 기기·기록 도우미 관리, 계정 지우기: 대시보드 설정 화면에서 하게 돼요 곧 생겨요

10. 자주 묻는 질문

우리 회사(서비스)가 내 아이디어를 볼 수 있나요?

아니요. 내용은 당신 기기에서 잠긴 채로 와요. 우리에게는 여는 열쇠가 없어요.

AI가 내 기록을 마음대로 공개하거나 지울 수 있나요?

아니요. 공개·삭제·공유는 AI 도구에 아예 없어요. 대시보드에서 본인이 기기 잠금을 풀어야만 할 수 있어요.

모든 변화가 기록되나요?

아니요. 기획 확정, 기능 완성, 피드백 반영처럼 의미 있는 변화만 남겨요. 오타 수정은 기록하지 않아요.

"AI 추정"은 뭐예요?

AI가 문서를 보고 "이제 기획 확정 단계 같아요"라고 짐작했다는 뜻이에요. 내가 직접 말하면 붙지 않아요.

GitHub를 안 쓰면 안 되나요?

가입 때 [나중에]로 건너뛸 수 있어요. 다만 증명 보관함이 있어야 우리 서비스가 없어져도 증명이 내 손에 남아요.

휴대폰 없이도 쓸 수 있나요?
