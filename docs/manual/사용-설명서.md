# Ideatrail 사용 설명서

> 처음 쓰는 분을 위한 안내예요. 어려운 말은 맨 아래 "낱말 풀이"에 모아 두었어요.
> **곧 생겨요**라고 적힌 기능은 아직 준비 중이에요.

---

## 1. Ideatrail이 뭐예요?

- AI(Claude Code)와 함께 아이디어를 다듬는 동안, **의미 있는 변화가 생길 때마다 저절로 기록**해 줘요.
- 기록마다 **날짜 증명**이 붙어요. "이 아이디어를 이날 이만큼 해 두었다"를 나중에 보여 줄 수 있어요.
- 내용은 **당신만 열 수 있게 잠가요.** 우리 서버도 열지 못해요.

## 2. 무엇이 필요해요?

| 필요한 것 | 왜 필요해요? |
|---|---|
| Mac (Windows는 곧 생겨요) | 기록이 남는 컴퓨터예요 |
| Claude Code | 평소 AI와 작업하는 곳이에요. 기록 도우미가 여기 들어가요 |
| Chrome 또는 Safari 최신 버전 | 가입 화면을 열어요 |
| Touch ID, 또는 컴퓨터 로그인 암호 | 컴퓨터 안에 **열쇠**를 만들 때 써요 |
| 휴대폰 (있으면 좋아요) | **예비 열쇠**를 만들어요. 없으면 건너뛸 수 있어요 |
| GitHub 계정 (무료) | 내 **증명 보관함**을 둘 곳이에요. 나중에 만들어도 돼요 |
| 비밀번호 관리자나 프린터 | **비상 열쇠**를 보관해요 |

시간은 **약 5분** 걸려요.

## 3. 설치하기

> 플러그인으로 묶어 내놓는 일은 곧 끝나요(곧 생겨요). 아래는 그때의 설치 방법이에요.

1. Claude Code를 열어요.
2. 이 한 줄을 붙여 넣고 Enter를 눌러요.

   ```
   /plugin install ideatrail
   ```

3. 끝이에요. 처음 무언가를 기록하려고 할 때 가입 창이 열려요.

> Claude Code가 처음부터 실행되지 않으면, Ideatrail 문제가 아니라 Claude Code 로그인 문제일 때가 많아요. Claude Code 안내대로 다시 로그인해 주세요.

## 4. 가입하기 — 한 단계씩

Claude Code에 이런 한 줄이 보이면 가입이 시작된 거예요.

> 가입하려고 브라우저 창을 열었어요. 약 5분이면 끝나요. 화면이 하라는 대로 마친 뒤 여기 Claude Code로 돌아와 주세요.

브라우저에 **"시작하기 전에"** 화면이 열려요. 여기에 앞으로 만들 4가지가 그림으로 나와요.

| 만드는 것 | 있는 곳 | 하는 일 |
|---|---|---|
| **열쇠** | 이 컴퓨터 | 내용을 여는 열쇠예요. 컴퓨터 밖으로 나가지 않아요 |
| **예비 열쇠** | 휴대폰 | 휴대폰으로도 보고, 컴퓨터를 잃어도 열 수 있어요 |
| **증명 보관함** | 내 GitHub | 날짜 증명과 잠긴 원문을 둬요. 우리 서비스가 없어져도 남아요 |
| **비상 열쇠** | 종이·비밀번호 관리자 | 기기를 모두 잃었을 때 쓰는 마지막 열쇠예요 |

> 화면에 **"연결할 컴퓨터: (내 컴퓨터 이름)"**이 보여요. 내 컴퓨터 이름이 아니거나, Claude Code가 연 창이 아니라면 그냥 닫으세요.

[시작하기]를 누르면 1단계부터 시작해요. 단계가 끝날 때마다 다음 화면 맨 위에 **"✓ 방금 한 일"**이 한 줄로 나와요.

### 1단계 · 이 컴퓨터에 열쇠 만들기

- **하는 일**: 내용을 여는 열쇠를 이 컴퓨터 안에 만들어요.
- **누를 것**: [열쇠 만들기]
- **뜨는 창**: 브라우저가 "저장할까요?" 하고 묻는 작은 창을 띄워요. 창에는 "패스키"라는 말이 보일 수 있어요(낱말 풀이 참고).
  - **Safari**: [계속] → Touch ID에 손가락을 대거나 컴퓨터 암호를 넣어요.
  - **Chrome**: 저장할 곳을 물을 수 있어요. 화면 안내대로 고른 뒤 Touch ID나 컴퓨터 암호를 넣어요. 잘 모르겠으면 Safari로 여는 게 가장 쉬워요.
  - Touch ID가 없어도 돼요. 컴퓨터 로그인 암호로 만들어져요.
- 가끔 **"한 번만 더 확인할게요"** 화면이 나와요. 열쇠를 마무리하려고 한 번 더 묻는 거예요. [확인]을 누르면 돼요.
- **끝나면**: "✓ 이 컴퓨터에 열쇠를 만들었어요. 이 열쇠 없이는 우리도 못 열어요"

### 2단계 · 휴대폰에 예비 열쇠 만들기

- **하는 일**: 휴대폰에도 열쇠를 하나 더 만들어요. 컴퓨터를 잃어도 휴대폰으로 열 수 있어요.
- **할 것**:
  1. 휴대폰 **카메라 앱**을 켜고 화면의 QR 코드를 비춰요.
  2. 카메라 화면에 링크가 뜨면 눌러요. 휴대폰 브라우저가 열려요.
  3. 휴대폰 화면에서 [이 기기 잠금으로 등록]을 누르고, 휴대폰 잠금(얼굴 인식, PIN 등)을 한 번 풀어요.
  4. 휴대폰에 "이 기기에서도 열려요"가 나오면 끝이에요. 컴퓨터 화면은 저절로 다음으로 넘어가요.
- QR은 **2분** 동안만 써요. 시간이 지나면 새 QR이 저절로 나와요.
- QR을 찍을 수 없으면 [QR을 찍을 수 없어요] → [링크 복사]로 **내 휴대폰에만** 보내세요. 이 링크는 한 번만 쓰는 비밀 열쇠예요. 다른 사람에게 보내면 안 돼요.
- 휴대폰이 지금 없으면 [휴대폰이 지금 없어요]를 눌러 건너뛰어요. 이때는 4단계 비상 열쇠를 꼭 만들어야 해요.
- **끝나면**: "✓ 휴대폰에 예비 열쇠를 만들었어요. 이제 휴대폰으로도 볼 수 있어요"

### 3단계 · 증명 보관함 만들기 (내 GitHub)

- **하는 일**: 내 GitHub에 **비공개** 보관함을 하나 만들어요. 날짜 증명과 잠긴 원문이 여기 쌓여요. 우리는 이 보관함 하나에만 들어갈 수 있어요.
- **할 것**:
  1. [GitHub에 보관함 만들기]를 눌러요.
  2. 화면 가운데에 **"ideatrail"** 이름의 작은 창이 떠요. 8자리 코드(예: `ABCD-1234`)가 보이고, **이미 복사돼 있어요.** [확인]을 눌러 닫아도 돼요.
  3. 브라우저에 GitHub 화면이 열려요. 로그인이 안 돼 있으면 로그인해요(계정이 없으면 여기서 무료로 만들 수 있어요).
  4. 코드 칸을 누르고 **붙여넣기**(Mac은 Cmd+V)를 한 뒤 [Continue]를 눌러요.
  5. GitHub가 **"Ideatrail"을 설치하고 승인할지** 물어요. [Install], [Authorize]를 눌러요.
  6. 가입 화면으로 돌아오면 저절로 다음 단계로 넘어가 있어요.
- 지금 하기 어려우면 [나중에]를 눌러도 돼요. 마지막 화면에서 [지금 만들기]로 다시 할 수 있어요.
- **끝나면**: "✓ 내 GitHub에 증명 보관함을 만들었어요. 우리 서비스가 없어져도 증명이 남아요"

### 4단계 · 비상 열쇠 [중요]

- **하는 일**: 컴퓨터와 휴대폰을 **모두** 잃었을 때 쓰는 마지막 열쇠를 만들어요. 우리도 대신 열어 드릴 수 없어서 꼭 보관해야 해요.
- **보관할 곳 고르기**:
  - **비밀번호 관리자에 저장** — iCloud 키체인, 1Password 같은 곳에 새 항목으로 붙여 넣어요. [비상 열쇠 복사]를 누르면 복사돼요.
  - **PDF로 인쇄** — [인쇄]를 누르면 인쇄 창이 떠요. 종이로 뽑거나 "PDF로 저장"을 골라요. 종이는 서랍처럼 안전한 곳에 둬요.
- 비상 열쇠는 **딱 한 번만** 보여요. 이 화면을 지나면 다시 볼 수 없어요. 4글자씩 끊어 천천히 확인하세요.
- 보관했으면 [다 보관했어요] → 제대로 보관했는지 **앞 4자리**를 적어요 → [확인하고 저장]을 누르면 Touch ID나 컴퓨터 암호를 한 번 물어요.
- 휴대폰을 등록했다면 [나중에]도 고를 수 있어요. 휴대폰을 건너뛰었다면 지금 꼭 만들어야 해요.
- **끝나면**: "✓ 비상 열쇠를 보관했어요. 기기를 모두 잃어도 이걸로 다시 열 수 있어요"

### 5단계 · 기록할 것 고르기

- **하는 일**: 이미 있는 문서로 아이디어마다 어디까지 왔는지 바로 채워요.
- 지금 Claude Code에서 열고 있는 프로젝트가 맨 위에 켜져 있고, 옆의 아이디어 폴더 몇 개가 꺼진 채 보여요. 원하는 것만 켜요.
- [기록하기]를 누르면 Touch ID나 컴퓨터 암호를 한 번 물어요. **고른 폴더만** 기록돼요.
- 아무것도 안 고르면 [새 기록부터 시작하기]가 돼요. 앞으로 생기는 변화부터 기록해요.
- 날짜 증명은 **오늘 날짜**로 찍혀요. 문서의 원래 날짜는 참고로 붙어요.
- 한 번에 200개 문서까지 가져와요. 나머지는 다음에 바뀔 때 기록해요.

### 마지막 화면 · 준비됐어요

- **만든 것**: 4가지가 어디 있는지, 언제 쓰는지 한눈에 다시 보여 줘요. 건너뛴 것은 "아직 안 만들었어요"로 나와요.
- **앞으로 이렇게 동작해요**: 저절로 기록 → 몇 시간 뒤 날짜 증명 → 공개·지우기는 나만.
- **이제 Claude Code로 돌아가세요**: [터미널로 돌아가기]를 누르거나 창을 닫으면 돼요.

## 5. 평소에 쓰기

따로 할 일은 없어요. **평소처럼 Claude Code와 작업하세요.** 의미 있는 변화(기획 확정, 기능 완성, 피드백 반영 등)가 생기면 기록 도우미가 남기고 터미널에 한 줄로 알려 줘요.

> 기록했어요 · 가계부 앱 · 단계: 기획 확정 (AI 추정)

오타 고치기 같은 작은 변화는 기록하지 않아요.

**이렇게 말해 보세요**

| 말하기 | 일어나는 일 |
|---|---|
| "아이디어 상태 알려줘" | 이 프로젝트의 지금 단계와 기록이 있는지 알려 줘요 |
| "지금 기록해 줘" | 방금 바뀐 내용을 기록해요 |
| "기획 확정됐어. 기록해 줘" | 단계를 '기획 확정'으로 남겨요 (내가 말했으니 "AI 추정"이 안 붙어요) |
| "옆 폴더의 예전 노트도 가져와 줘" | 그 폴더를 기록할지 묻는 요청을 보내요. 허락하는 화면은 곧 생겨요 |

- 작업을 마칠 때 아직 기록하지 않은 변경이 있으면, Claude가 **"ideatrail에 남길까요?"**라고 한 번 물어요.
- 인터넷이 끊겨도 괜찮아요. 연결되면 저절로 올라가요.
- 공개로 바꾸기·지우기·공유는 **AI가 할 수 없어요.** 대시보드에서 본인만 직접 할 수 있어요(대시보드는 곧 생겨요).

## 6. 휴대폰으로 보기

- 2단계에서 예비 열쇠를 만들었다면, 휴대폰에서 기록을 볼 준비가 된 거예요.
- 휴대폰 브라우저 메뉴(⋮)에서 **"홈 화면에 추가"**를 누르면 앱처럼 열 수 있어요.
- 기록을 둘러보는 **대시보드 화면은 곧 생겨요.**

## 7. 내 데이터는 어떻게 돼요?

- 내용은 **이 컴퓨터에서 잠근 뒤** 보내요. 우리 서버에는 **잠긴 기록과 날짜 증명만** 있고, 우리는 열 수 없어요.
- 여는 열쇠는 내 컴퓨터와 휴대폰 안에만 있어요. 우리 서버로 오지 않아요.
- **증명 보관함(내 GitHub)**에 날짜 증명과 잠긴 원문이 쌓여요. 우리 서비스가 문을 닫아도 당신 손에 남아요. 이 보관함에는 내 컴퓨터의 기록 도우미만 써요. 우리 서버는 GitHub에 쓰지 않고, 다른 저장소에는 들어가지 못해요.
- 이 컴퓨터의 홈 폴더에도 `ideatrail-증명` 폴더로 사본이 하나 더 남아요.
- 기록 도우미가 쓰는 폴더는 AI도 열지 못하게 막혀 있어요.
- 날짜 증명은 몇 시간 뒤 공개 블록체인에 새겨져요. 그 뒤에는 누구도 날짜를 바꿀 수 없어요.

## 8. 기기를 잃어버렸다면

| 잃은 것 | 이렇게 하세요 |
|---|---|
| **컴퓨터만** | 휴대폰(예비 열쇠)으로 계속 열 수 있어요. 새 컴퓨터는 휴대폰에서 [새 기기 추가]로 등록해요(곧 생겨요) |
| **휴대폰만** | 컴퓨터(열쇠)로 계속 열 수 있어요. 새 휴대폰은 컴퓨터에서 [새 기기 추가]로 등록해요(곧 생겨요) |
| **둘 다** | **비상 열쇠**로 새 기기에서 다시 열어요(곧 생겨요). 비상 열쇠가 없으면 우리도 열어 드릴 수 없어요 |

> 그래서 비상 열쇠가 [중요]예요. 아직 안 만들었다면 설정에서 만들 수 있게 될 거예요(곧 생겨요).

## 9. 연결 끊기와 계정 지우기

- **이 컴퓨터에서 그만 쓰기**: Claude Code의 `/plugin` 메뉴에서 ideatrail을 끄거나 지우면 더 이상 기록하지 않아요.
- **GitHub 연결 끊기**: GitHub 설정 → Applications에서 Ideatrail을 지우면 기록 도우미가 더는 보관함에 쓸 수 없어요. 이미 쌓인 증명은 보관함에 그대로 남아요. 보관함 자체를 지우는 것은 GitHub에서 직접 할 수 있어요.
- **기기·기록 도우미 관리, 계정 지우기**: 대시보드 설정 화면에서 하게 돼요(곧 생겨요).

## 10. 자주 묻는 질문

**Q1. 우리 회사(서비스)가 내 아이디어를 볼 수 있나요?**
아니요. 내용은 당신 기기에서 잠긴 채로 와요. 우리에게는 여는 열쇠가 없어요.

**Q2. AI가 내 기록을 마음대로 공개하거나 지울 수 있나요?**
아니요. 공개·삭제·공유는 AI 도구에 아예 없어요. 대시보드에서 본인이 기기 잠금을 풀어야만 할 수 있어요(대시보드는 곧 생겨요).

**Q3. 모든 변화가 기록되나요?**
아니요. 기획 확정, 기능 완성, 피드백 반영처럼 의미 있는 변화만 남겨요. 오타 수정은 기록하지 않아요.

**Q4. "AI 추정"은 뭐예요?**
AI가 문서를 보고 "이제 기획 확정 단계 같아요"라고 짐작했다는 뜻이에요. 내가 직접 말하면 붙지 않아요.

**Q5. GitHub를 안 쓰면 안 되나요?**
가입 때 [나중에]로 건너뛸 수 있어요. 다만 증명 보관함이 있어야 우리 서비스가 없어져도 증명이 내 손에 남아요.

**Q6. 휴대폰 없이도 쓸 수 있나요?**
네. 대신 비상 열쇠는 꼭 만들어야 해요. 컴퓨터를 잃으면 비상 열쇠만 남거든요.

**Q7. 비상 열쇠를 잃어버렸어요.**
컴퓨터나 휴대폰이 남아 있다면 계속 쓸 수 있어요. 새 비상 열쇠를 만드는 화면은 곧 생겨요. 기기도 비상 열쇠도 모두 잃으면 우리도 열어 드릴 수 없어요.

**Q8. 가입 링크가 "시간이 지났어요"라고 나와요.**
Claude Code에 "설치 링크 다시 줘"라고 말해 주세요. 새 가입 창이 열려요.

**Q9. Windows에서도 되나요?**
곧 생겨요. 지금은 Mac에서 먼저 써 볼 수 있어요.
