# Ideatrail 사용 설명서

> 처음 쓰는 분을 위한 안내예요. 어려운 말은 맨 아래 "낱말 풀이"에 모아 두었어요.
> **곧 생겨요**라고 적힌 기능은 아직 준비 중이에요.
> 이 설명서에서 **Ideatrail**은 서비스와 그 서버를, **사용자**는 이 설명서를 읽는 분을 뜻해요.

---

## 1. Ideatrail이 뭐예요?

### AI와 이야기하다 "이거 괜찮은데?" 싶으면, 한마디면 돼요

AI와 이야기하다 보면 좋은 생각이 나와요. 그런데 대화가 길어지면 묻혀서, 며칠 뒤엔 무엇을 왜 골랐는지 다시 찾기 어렵죠.
Ideatrail을 쓰면 **"기록해 줘"** 한마디로 AI가 그 순간을 정리해서, **날짜 증명과 함께** 남겨요. 이 말은 **"박제해"처럼 사용자만의 기록 말**로 바꿀 수 있어요(6장).

**이렇게 써요**

> **사용자**: 좋아, 이 방향으로 가자. 왜 이걸 골랐는지까지 기록해 줘
>
> **터미널**: 기록했어요 · 가계부 앱 · 단계: 기획 확정 (AI 추정)

**나중엔 이렇게 한눈에 봐요** (한눈에 보는 화면은 곧 생겨요)

| 언제 | 단계 | 정리된 내용 |
|---|---|---|
| 11월 3일 | 아이디어 | 처음 떠올린 생각 |
| 11월 18일 | 기획 확정 | **고른 것** 카드 연동 없이 직접 입력 · **이유** 금융 정보를 넘기기 싫어서 · **안 하기로 한 것** 가족 공유 |

### 써 보면 좋은 점 세 가지

**① 말 한마디로 정리돼요**
- "기록해 줘"라고 하면 AI가 대화에서 **무엇을 골랐고, 왜 골랐고, 무엇을 안 하기로 했는지**를 짧은 메모로 정리해 기록해요.
- 말하지 않아도 문서에 **의미 있는 변화**(기획 확정, 기능 완성, 피드백 반영 등)가 생기면 알아서 기록해요. 오타 고치기 같은 작은 변화는 남기지 않아요.

**② 나중에 찾기 쉬워요**
- 아이디어마다 **어느 단계까지 왔는지**(아이디어 → 기획 확정 → MVP 완료 → 기능 완성), 그때그때 **고른 것과 그 이유**가 순서대로 쌓여요.
- 지금은 Claude Code에 **"아이디어 상태 알려줘"**라고 물으면 알려 줘요. 휴대폰·다른 기기에서 한눈에 보는 화면(대시보드)은 곧 생겨요.
- 사용자가 원하면 그 기록의 **파일로 가는 경로**도 알려 줘요. 그 파일을 여는 순간부터는 사용자의 기기·GitHub 계정의 보안에 달려 있어요.
- 기록마다 날짜 증명이 붙어서, "이 생각을 이날 이만큼 해 두었다"를 나중에 누구에게나 보여 줄 수 있어요.

**③ 안심하고 맡겨요**
- 기록 내용은 잠긴 채 **사용자의 컴퓨터와 사용자의 GitHub**에만 있고, **사용자의 열쇠로 사용자의 기기에서만** 열려요.
- Ideatrail 서버에 남는 것은 **기록 일시와 파일 지문(기록마다 32바이트)**뿐이에요. 지문은 내용에서 한 방향으로만 뽑은 값이라, **서버가 해킹돼도 내용을 거꾸로 알아낼 수 없어요.**
- 무엇이 어디에 있는지는 2장에 자세히 있어요.

가입하면서 아래 네 가지를 만들어요. 이 설명서는 이 네 가지 이름으로 이야기해요.

| 만드는 것 | 있는 곳 | 하는 일 |
|---|---|---|
| **열쇠** | 사용자의 컴퓨터 | 기록을 여는 열쇠예요. 컴퓨터 밖으로 나가지 않아요 |
| **예비 열쇠** | 사용자의 휴대폰 | 휴대폰으로도 보고, 컴퓨터를 잃어도 열 수 있어요 |
| **증명 보관함** | 사용자의 GitHub | 잠긴 기록 사본과 날짜 증명을 둬요. Ideatrail이 없어져도 남아요 |
| **비상 열쇠** | 종이·비밀번호 관리자 | 기기를 모두 잃었을 때 쓰는 마지막 열쇠예요 |

## 2. 어디에 무엇이 저장되나요? — 그래서 안전해요

### 한눈에 보기

| 곳 | 무엇이 있나요 | 누가 열 수 있나요 |
|---|---|---|
| **사용자의 컴퓨터** | 평소 작업하던 파일(원래 자리 그대로. Ideatrail은 옮기거나 바꾸지 않아요) · **열쇠**(기기 잠금 안에) · 증명 사본(`ideatrail-증명` 폴더: 파일 지문과 날짜 증명, 내용 없음) | 사용자 |
| **사용자의 GitHub** (비공개 증명 보관함) | 기록한 **그 순간의 원본 사본과 메모 — 잠긴 채** · 날짜 증명 | 사용자의 열쇠로만. GitHub도 Ideatrail도 못 열어요 |
| **사용자의 휴대폰** | **예비 열쇠** | 사용자(휴대폰 잠금) |
| **종이·비밀번호 관리자** | **비상 열쇠** | 사용자 |
| **Ideatrail 서버** | **기록 일시 · 파일 지문(기록마다 32바이트) · 날짜 증명 영수증**, 그리고 Ideatrail도 풀 수 없게 잠긴 작은 정보 몇 가지(아래) | 일시와 지문은 Ideatrail이 볼 수 있지만, 이것만으로는 내용을 알 수 없어요 |

### 컴퓨터와 GitHub은 무엇이 달라요?

| | 사용자의 컴퓨터 | 사용자의 GitHub |
|---|---|---|
| 무엇 | 지금 작업 중인 파일 | 기록한 순간의 모습 |
| 바뀌나요 | 작업하면 계속 바뀌어요 | 한 번 쌓이면 바뀌지 않아요 |
| 잠겨 있나요 | 평소 파일 그대로예요 | 잠긴 채로 쌓여요 |
| 컴퓨터를 잃으면 | 함께 사라져요 | 그대로 남아요 |

> 원본 파일이 5MB를 넘거나 이미지·영상이면 GitHub에는 사본 없이 **파일 지문만** 남겨요. 날짜 증명은 똑같이 붙어요.

### Ideatrail 서버에 없는 것

- 메모, 원본 파일 같은 **기록 내용**
- 기록을 여는 **열쇠**
- **이메일이나 이름** (가입할 때 받지 않아요)

### Ideatrail 서버에 잠긴 채로만 있는 것

화면을 그리려면 필요해서, 사용자의 기기가 잠가서 보내는 작은 정보예요. 셋 다 **사용자의 열쇠로만 풀려요. Ideatrail은 못 풀어요.**

1. **목록 이름표** — 목록에 보일 폴더 이름·파일 이름·단계
2. **열쇠 상자** — 사용자의 컴퓨터·휴대폰·비상 열쇠가 같은 기록을 열 수 있게 해 주는 상자
3. **GitHub 출입증** — 대시보드가 사용자의 증명 보관함을 읽을 때 써요

### 그래서 이런 일이 생겨도 괜찮아요

| 만약 | 어떻게 되나요 |
|---|---|
| **Ideatrail 서버가 털리면** | 가져갈 내용이 없어요. 파일 지문으로는 내용을 되살리거나 짐작할 수 없고, 잠긴 정보는 열쇠가 없어 풀 수 없어요 |
| **Ideatrail 직원이 보려고 해도** | 마찬가지예요. Ideatrail에는 열쇠가 없어요 |
| **GitHub 계정이 털리거나 GitHub가 들여다봐도** | 잠긴 사본만 있어요. 사용자의 열쇠 없이는 못 열어요 |
| **Ideatrail이 문을 닫아도** | 기록 사본은 사용자의 GitHub에, 작업 파일은 사용자의 컴퓨터에 그대로 있어요. 날짜 증명은 공개 블록체인에 새겨져서, Ideatrail 없이도 누구나 확인할 수 있어요 |
| **컴퓨터를 잃어도** | 휴대폰(예비 열쇠)이나 비상 열쇠로 열고, GitHub의 사본으로 되찾아요(되찾는 화면은 곧 생겨요) |
| **AI가 마음대로 하려 해도** | 기록 도우미 폴더는 AI도 열지 못하게 막혀 있어요. 공개·삭제·공유는 AI가 쓰는 도구에 아예 없어요 |

### 기록을 볼 때는

사용자의 기기 브라우저가 사용자의 GitHub에서 잠긴 사본을 가져와 **그 자리에서 사용자의 열쇠로** 풀어요. 푼 내용은 Ideatrail 서버로 보내지 않아요(기록을 둘러보는 대시보드는 곧 생겨요).

### 잠그는 방식은요

Ideatrail이 새로 만든 방식이 아니에요. **공개되고 검증된 표준 암호 방식**을 써요(이름은 낱말 풀이에 있어요). 날짜는 기록 몇 시간 뒤 공개 블록체인에 새겨지고, 그 뒤에는 누구도 바꿀 수 없어요.

## 3. 무엇이 필요해요?

| 필요한 것 | 왜 필요해요? |
|---|---|
| Mac (Windows는 곧 생겨요) | 기록이 남는 컴퓨터예요 |
| Claude Code | 평소 AI와 작업하는 곳이에요. 기록 도우미가 여기 들어가요 |
| Chrome 또는 Safari 최신 버전 | 가입 화면을 열어요 |
| Touch ID, 또는 컴퓨터 로그인 암호 | 컴퓨터 안에 **열쇠**를 만들 때 써요 |
| 휴대폰 (있으면 좋아요) | **예비 열쇠**를 만들어요. 없으면 건너뛸 수 있어요 |
| GitHub 계정 (무료) | 사용자의 **증명 보관함**을 둘 곳이에요. 나중에 만들어도 돼요 |
| 비밀번호 관리자나 프린터 | **비상 열쇠**를 보관해요 |

시간은 **약 5분** 걸려요.

## 4. 설치하기

> 플러그인으로 묶어 내놓는 일은 곧 끝나요(곧 생겨요). 아래는 그때의 설치 방법이에요.

1. Claude Code를 열어요.
2. 이 한 줄을 붙여 넣고 Enter를 눌러요.

   ```
   /plugin install ideatrail
   ```

3. 끝이에요. 처음 무언가를 기록하려고 할 때 가입 창이 열려요.

> Claude Code가 처음부터 실행되지 않으면, Ideatrail 문제가 아니라 Claude Code 로그인 문제일 때가 많아요. Claude Code 안내대로 다시 로그인해 주세요.

## 5. 가입하기 — 한 단계씩

Claude Code에 이런 한 줄이 보이면 가입이 시작된 거예요.

> 가입하려고 브라우저 창을 열었어요. 약 5분이면 끝나요. 화면이 하라는 대로 마친 뒤 여기 Claude Code로 돌아와 주세요.

브라우저에 첫 화면이 열려요. **"이렇게 써요"** 예시와 **써 보면 좋은 점 세 가지**, 그리고 **안심하고 쓰는 이유**(앞으로 만들 네 가지와 Ideatrail 서버에 무엇이 남는지)가 나와요. 다 읽었으면 [시작하기]를 눌러요.

> 화면에 **"연결할 컴퓨터: (컴퓨터 이름)"**이 보여요. 사용자의 컴퓨터 이름이 아니거나, Claude Code가 연 창이 아니라면 그냥 닫으세요.

[시작하기]를 누르면 1단계부터 시작해요. 단계가 끝날 때마다 다음 화면 맨 위에 **"✓ 방금 한 일"**이 한 줄로 나와요.

### 1단계 · 이 컴퓨터에 열쇠 만들기

- **하는 일**: 기록을 여는 열쇠를 이 컴퓨터 안에 만들어요. 열쇠는 Ideatrail 서버로 가지 않아요.
- **누를 것**: [열쇠 만들기]
- **뜨는 창**: 브라우저가 "저장할까요?" 하고 묻는 작은 창을 띄워요. 창에는 "패스키"라는 말이 보일 수 있어요(낱말 풀이 참고).
  - **Safari**: [계속] → Touch ID에 손가락을 대거나 컴퓨터 암호를 넣어요.
  - **Chrome**: 저장할 곳을 물을 수 있어요. 화면 안내대로 고른 뒤 Touch ID나 컴퓨터 암호를 넣어요. 잘 모르겠으면 Safari로 여는 게 가장 쉬워요.
  - Touch ID가 없어도 돼요. 컴퓨터 로그인 암호로 만들어져요.
- 가끔 **"한 번만 더 확인할게요"** 화면이 나와요. 열쇠를 마무리하려고 한 번 더 묻는 거예요. [확인]을 누르면 돼요.
- **끝나면**: "✓ 이 컴퓨터에 열쇠를 만들었어요. 사용자의 기록은 이 열쇠로만 열려요"

### 2단계 · 휴대폰에 예비 열쇠 만들기

- **하는 일**: 휴대폰에도 열쇠를 하나 더 만들어요. 컴퓨터를 잃어도 휴대폰으로 열 수 있어요.
- **할 것**:
  1. 휴대폰 **카메라 앱**을 켜고 화면의 QR 코드를 비춰요.
  2. 카메라 화면에 링크가 뜨면 눌러요. 휴대폰 브라우저가 열려요.
  3. 휴대폰 화면에서 [이 기기 잠금으로 등록]을 누르고, 휴대폰 잠금(얼굴 인식, PIN 등)을 한 번 풀어요.
  4. 휴대폰에 "이 기기에서도 열려요"가 나오면 끝이에요. 컴퓨터 화면은 저절로 다음으로 넘어가요.
- QR은 **2분** 동안만 써요. 시간이 지나면 새 QR이 저절로 나와요.
- QR을 찍을 수 없으면 [QR을 찍을 수 없어요] → [링크 복사]로 **사용자의 휴대폰에만** 보내세요. 이 링크는 한 번만 쓰는 비밀 열쇠예요. 다른 사람에게 보내면 안 돼요.
- 휴대폰이 지금 없으면 [휴대폰이 지금 없어요]를 눌러 건너뛰어요. 이때는 4단계 비상 열쇠를 꼭 만들어야 해요.
- **끝나면**: "✓ 휴대폰에 예비 열쇠를 만들었어요. 이제 휴대폰으로도 볼 수 있어요"

### 3단계 · 증명 보관함 만들기 (사용자의 GitHub)

- **하는 일**: 사용자의 GitHub에 **비공개** 보관함을 하나 만들어요. 잠긴 기록 사본과 날짜 증명이 여기 쌓여요. Ideatrail 앱은 이 보관함 하나에만 쓸 수 있어요.
- **할 것**:
  1. [GitHub에 보관함 만들기]를 눌러요.
  2. 화면 가운데에 **"ideatrail"** 이름의 작은 창이 떠요. 8자리 코드(예: `ABCD-1234`)가 보이고, **이미 복사돼 있어요.** [확인]을 눌러 닫아도 돼요.
  3. 브라우저에 GitHub 화면이 열려요. 로그인이 안 돼 있으면 로그인해요(계정이 없으면 여기서 무료로 만들 수 있어요).
  4. 코드 칸을 누르고 **붙여넣기**(Mac은 Cmd+V)를 한 뒤 [Continue]를 눌러요.
  5. GitHub가 **"Ideatrail"을 설치하고 승인할지** 물어요. [Install], [Authorize]를 눌러요.
  6. 가입 화면으로 돌아오면 저절로 다음 단계로 넘어가 있어요.
- 지금 하기 어려우면 [나중에]를 눌러도 돼요. 마지막 화면에서 [지금 만들기]로 다시 할 수 있어요.
- **끝나면**: "✓ 사용자의 GitHub에 증명 보관함을 만들었어요. Ideatrail이 없어져도 증명이 남아요"

### 4단계 · 비상 열쇠 [중요]

- **하는 일**: 컴퓨터와 휴대폰을 **모두** 잃었을 때 쓰는 마지막 열쇠를 만들어요. Ideatrail도 대신 열어 드릴 수 없어서 꼭 보관해야 해요.
- **보관할 곳 고르기**:
  - **비밀번호 관리자에 저장** — iCloud 키체인, 1Password 같은 곳에 새 항목으로 붙여 넣어요. [비상 열쇠 복사]를 누르면 복사돼요.
  - **PDF로 인쇄** — [인쇄]를 누르면 인쇄 창이 떠요. 종이로 뽑거나 "PDF로 저장"을 골라요. 종이는 서랍처럼 안전한 곳에 둬요.
- 비상 열쇠는 **딱 한 번만** 보여요. 이 화면을 지나면 다시 볼 수 없어요. 4글자씩 끊어 천천히 확인하세요.
- 보관했으면 [다 보관했어요] → 제대로 보관했는지 **앞 4자리**를 적어요 → [확인하고 저장]을 누르면 Touch ID나 컴퓨터 암호를 한 번 물어요.
- 휴대폰을 등록했다면 [나중에]도 고를 수 있어요. 휴대폰을 건너뛰었다면 지금 꼭 만들어야 해요.
- **끝나면**: "✓ 비상 열쇠를 보관했어요. 기기를 모두 잃어도 이걸로 다시 열 수 있어요"

### 5단계 · 기록할 것 고르기

- **하는 일**: 이미 있는 문서로 아이디어마다 어디까지 왔는지 바로 채워요.
- 지금 Claude Code에서 열고 있는 프로젝트가 맨 위에 켜져 있고, 옆의 아이디어 폴더 몇 개가 꺼진 채 보여요. 원하는 것만 켜요.
- [기록하기]를 누르면 Touch ID나 컴퓨터 암호를 한 번 물어요. **고른 폴더만** 기록돼요.
- 아무것도 안 고르면 [새 기록부터 시작하기]가 돼요. 앞으로 생기는 변화부터 기록해요.
- 날짜 증명은 **오늘 날짜**로 찍혀요. 문서의 원래 날짜는 참고로 붙어요.
- 한 번에 200개 문서까지 가져와요. 나머지는 다음에 바뀔 때 기록해요.

### 마지막 화면 · 준비됐어요

- **만든 것**: 4가지가 어디 있는지, 언제 쓰는지 한눈에 다시 보여 줘요. 건너뛴 것은 "아직 안 만들었어요"로 나와요.
- **앞으로 이렇게 동작해요**: "기록해 줘" 또는 저절로 기록 → 몇 시간 뒤 날짜 증명 → 공개·지우기는 사용자만.
- **이제 Claude Code로 돌아가세요**: [터미널로 돌아가기]를 누르거나 창을 닫으면 돼요.

## 6. 평소에 쓰기

**평소처럼 Claude Code와 이야기하세요.** "이거 괜찮은데?" 싶은 순간엔 **"기록해 줘"** 한마디면 돼요. 말하지 않아도 의미 있는 변화(기획 확정, 기능 완성, 피드백 반영 등)가 생기면 기록 도우미가 남기고 터미널에 한 줄로 알려 줘요.

> 기록했어요 · 가계부 앱 · 단계: 기획 확정 (AI 추정)

오타 고치기 같은 작은 변화는 기록하지 않아요.

**이렇게 말해 보세요**

| 말하기 | 일어나는 일 |
|---|---|
| "기록해 줘" (또는 사용자가 정한 기록 말) | 대화에서 정한 것은 고른 것·이유·안 하기로 한 것을 메모로 정리해 기록하고, 바뀐 문서는 그대로 기록해요 |
| "아이디어 상태 알려줘" | 이 프로젝트의 지금 단계와 기록이 있는지 알려 줘요 |
| "기록 말을 '박제해'로 바꿔 줘" | 기록을 부르는 말을 바꿔요. 다음 대화부터 그 말에도 기록해요. 5개까지, 하나에 2~20자이고, 이 컴퓨터에만 저장돼요. 저장하면 터미널에 정한 말이 그대로 보여요 |
| "기록 말 처음대로 돌려 줘" | 사용자가 정한 말을 지우고 "기록해 줘"만 남겨요 |
| "기획 확정됐어. 기록해 줘" | 단계를 '기획 확정'으로 남겨요 (사용자가 직접 말했으니 "AI 추정"이 안 붙어요) |
| "옆 폴더의 예전 노트도 가져와 줘" | 그 폴더를 기록할지 묻는 요청을 보내요. 허락하는 화면은 곧 생겨요 |

- 작업을 마칠 때 아직 기록하지 않은 변경이 있으면, Claude가 **"ideatrail에 남길까요?"**라고 한 번 물어요.
- 인터넷이 끊겨도 괜찮아요. 연결되면 저절로 올라가요.
- 공개로 바꾸기·지우기·공유는 **AI가 할 수 없어요.** 대시보드에서 사용자만 직접 할 수 있어요(대시보드는 곧 생겨요).

## 7. 휴대폰으로 보기

- 2단계에서 예비 열쇠를 만들었다면, 휴대폰에서 기록을 볼 준비가 된 거예요.
- 휴대폰 브라우저 메뉴(⋮)에서 **"홈 화면에 추가"**를 누르면 앱처럼 열 수 있어요.

## 10. 자주 묻는 질문

**Q1. Ideatrail이 사용자의 아이디어를 볼 수 있나요?**
아니요. 기록 내용은 Ideatrail 서버로 오지 않아요. Ideatrail에는 기록 일시와 파일 지문만 있고, 여는 열쇠도 없어요. 자세한 것은 2장을 보세요.

**Q2. AI가 사용자의 기록을 마음대로 공개하거나 지울 수 있나요?**
아니요. 공개·삭제·공유는 AI 도구에 아예 없어요. 대시보드에서 사용자가 기기 잠금을 풀어야만 할 수 있어요(대시보드는 곧 생겨요).

**Q3. 모든 변화가 기록되나요?**
아니요. 기획 확정, 기능 완성, 피드백 반영처럼 의미 있는 변화만 남겨요. 오타 수정은 기록하지 않아요.

**Q4. "AI 추정"은 뭐예요?**
AI가 문서를 보고 "이제 기획 확정 단계 같아요"라고 짐작했다는 뜻이에요. 사용자가 직접 말하면 붙지 않아요.

**Q5. GitHub를 안 쓰면 안 되나요?**
가입 때 [나중에]로 건너뛸 수 있어요. 다만 증명 보관함이 있어야 Ideatrail이 없어져도 기록 사본과 증명이 사용자 손에 남아요.

**Q6. 휴대폰 없이도 쓸 수 있나요?**
네. 대신 비상 열쇠는 꼭 만들어야 해요. 컴퓨터를 잃으면 비상 열쇠만 남거든요.

**Q7. 비상 열쇠를 잃어버렸어요.**
컴퓨터나 휴대폰이 남아 있다면 계속 쓸 수 있어요. 새 비상 열쇠를 만드는 화면은 곧 생겨요. 기기도 비상 열쇠도 모두 잃으면 Ideatrail도 열어 드릴 수 없어요.

**Q8. 가입 링크가 "시간이 지났어요"라고 나와요.**
Claude Code에 "설치 링크 다시 줘"라고 말해 주세요. 새 가입 창이 열려요.

**Q9. Windows에서도 되나요?**
곧 생겨요. 지금은 Mac에서 먼저 써 볼 수 있어요.

## 11. 낱말 풀이 (궁금한 분만)

| 화면에서 쓰는 말 | 기술 이름 | 한 줄 설명 |
|---|---|---|
| 열쇠 | 패스키(WebAuthn) + PRF 확장 | 기기 잠금(Touch ID·PIN·암호)으로만 꺼낼 수 있는 비밀 값이에요 |
| 예비 열쇠 | 두 번째 기기의 패스키 | 휴대폰에 따로 만든 열쇠예요 |
| 비상 열쇠 | 복구 키 | 종이·비밀번호 관리자에 두는 마지막 열쇠예요 |
| 열쇠 상자 | 키 봉투(PRF로 감싼 계정 키) | 여러 기기의 열쇠가 같은 기록을 열게 해 줘요. 사용자의 열쇠로만 풀려요 |
| 증명 보관함 | 사용자의 GitHub 비공개 저장소 | Ideatrail GitHub App이 이 저장소 하나에만 써요 |
| 기록 도우미 | 엔진(Claude Code 플러그인의 MCP 서버·훅) | 사용자의 컴퓨터에서 기록을 잠가 보내는 프로그램이에요. 잠그기만 하고 열지는 못해요 |
| 잠긴 기록 | 봉인(HPKE)·암호화(XChaCha20-Poly1305) | 열쇠가 있어야만 풀리는 상태예요. 누구나 확인할 수 있는 공개 표준 방식이에요 |
| 날짜 증명 | 타임스탬프(OpenTimestamps) | 파일 지문을 공개 블록체인에 새겨 날짜를 증명해요 |
| 파일 지문 | 해시(SHA-256, 32바이트) | 내용이 한 글자만 바뀌어도 완전히 달라지는 값이에요. 무작위 값을 섞어 만들어 내용을 짐작할 수 없어요 |
| 8자리 코드 | GitHub 기기 인증(device flow) 코드 | GitHub에 "이 컴퓨터가 맞다"고 알려 주는 일회용 코드예요 |
